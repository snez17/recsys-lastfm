# 🎵 RecSys — рекомендательная система на основе прослушиваний Last.fm

## 📌 О проекте

Pet-проект по построению рекомендательной системы музыкальных треков на основе данных о прослушиваниях пользователей Last.fm за 2007 год.

Реализовано несколько моделей рекомендаций, их сравнение и API для выдачи рекомендаций.

---

## 📊 Данные

- **Источник:** Last.fm (2007 год)
- **Пользователей:** 721
- **Треков:** ~47,000
- **Прослушиваний:** ~54,000 (после фильтрации)

---

## 🧠 Модели

| Модель | Описание |
|--------|----------|
| **Popular** | Бейзлайн — самые популярные треки |
| **UserTop** | Топ треков, которые пользователь слушал чаще всего |
| **ItemKNN** | Похожие треки (item-item collaborative filtering) |
| **ALS** | Матричная факторизация (Alternating Least Squares) |
| **Hybrid** | Гибридная стратегия: UserKNN → UserTop → Popular |

---

## 📈 Результаты (Hit Rate)

| Модель | Hit Rate | Precision | NDCG |
|--------|----------|-----------|------|
| Popular | **18.76%** | 0.79% | 0.95% |
| Hybrid | 13.06% | 0.44% | 0.59% |
| ItemKNN | 4.51% | 0.12% | 0.17% |
| ALS | 4.51% | 0.13% | 0.18% |
| UserTop | 0.48% | 0.01% | 0.03% |

**Вывод:** Popular — сильный бейзлайн. Hybrid требует настройки гиперпараметров.

## 🚀 Запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Обучение моделей

```bash
python src/train.py
```

### 3. Запуск API

```bash
python src/main.py
```

### 4. Запрос рекомендаций

```
GET http://localhost:8000/recommend/user_000044?n=10
```
